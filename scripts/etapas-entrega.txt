# Etapas de la subida progresiva al GitLab del evento (día 1). Las usa scripts/subir-por-etapas.sh.
#
# Cada etapa es un commit sobre la copia limpia (la de scripts/preparar-entrega.sh) y AÑADE sus archivos
# a lo ya subido. El reparto sigue la AUTORÍA REAL de cada parte, tal como la acordó el equipo:
#   - frontend/ (React + Vite + TypeScript), rama javier de GitHub  -> Javier Rodríguez, rama javier
#   - backend/  (Python + FastAPI, agente e ingesta), rama enggel  -> Enggel Rodríguez, rama enggel
#   - estructura inicial, material del reto y documentación de entrega -> Diego Landaeta, rama diego
# El orden sigue la cronología de GitHub (git log --date=iso): estructura (11:34), backend (13:42-14:27),
# frontend (14:08) y, al final, la documentación de entrega.
#
# AVISO DE AUTORÍA (ver scripts/README-entrega.md, «Autoría»): en GitHub los 4 commits de la rama enggel
# figuran firmados por "Diego Landaeta" y el de la rama javier por "Javier <javier@equipo.local>" (correo
# que no es real). Por eso el autor de esas etapas NO se toma de git: se indica con --autor-enggel y
# --autor-javier ("Nombre Apellido <correo con el que cada uno entra al GitLab del evento>").
#
# Formato: una línea "clave valor"; "etapa <id>" abre una etapa nueva.
#   etapa    identificador corto (único)
#   mensaje  mensaje del commit, en castellano
#   autor    "Nombre Apellido <correo>", o AUTOR_JAVIER / AUTOR_ENGGEL (se sustituyen por --autor-javier /
#            --autor-enggel, obligatorios)
#   rama     rama de trabajo de GitLab que recibe el commit: diego, javier o enggel
#   ruta     archivos que incorpora (repetible). Misma sintaxis que exclusiones-entrega.txt:
#            sin "/" coincide en cualquier carpeta, por eso los archivos de la raíz llevan "/" delante;
#            "carpeta/" es todo su contenido; "*" no cruza carpetas; "!patrón" lo quita de ESTA etapa.
#
# Reglas de reparto: cada archivo de la copia limpia va a la PRIMERA etapa que lo incluye; ningún
# archivo puede quedar sin etapa, ninguna etapa puede quedar vacía y una ruta que no coincide con nada
# es un error (así se detectan erratas y archivos renombrados). Lo excluido nunca llega aquí.
